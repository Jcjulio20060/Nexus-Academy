## Design Specificity Verdict

The console shell metaphor (// AGORA, status bar, rail, tab bar) is genuinely authored for this product. The coffee-caramel-teal palette is distinctive. Glassmorphism is well-executed. However, the admin dashboard is a different visual language entirely — different radius (6px), different font sizes, no glass panels.

## Priority Issues

- **[P1] Token drift: 40+ inline font sizes and 8+ radii outside DESIGN.md scale** — The design system exists on paper but the code doesn't follow it. Fix: replace inline values with CSS custom properties or documented scale steps.
- **[P2] Side-tab accent borders flagged as AI slop** — borderLeft: 3px solid in CurrentClass.tsx and Card.tsx. CurrentClass is a legitimate exception; Card.tsx accent prop should be deprecated.
- **[P2] Admin dashboard visual disconnect** — Uses 6px radius, different font sizes, no glass panels. Align with console language.
- **[P2] Empty states are dead ends** — "Nenhuma aula agendada" with no guidance, illustration, or action.
- **[P3] Progress bar animates width (layout thrash)** — Should use transform: scaleX() instead.
